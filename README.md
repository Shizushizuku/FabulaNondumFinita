# 留待明日

打开 `index.html` 即可游玩，也可将本文件夹作为静态网页发布到 GitHub Pages。网页和图片均在本文件夹内，无需安装运行依赖。

开场白使用 `content/开场白.md` 中的五段原文。当前浏览器首次游玩先显示四页操作说明，由玩家手动翻页，可返回上一页。随后开场白全屏居中渐显渐隐，最后经过黑场与「始」字画面进入正文；后续游玩自动跳过，并在右上角显示回顾入口。回顾期间暂停正文，结束后恢复原位置。切到后台会暂停开场白计时。正常动画模式下，开场白总长 30 秒；结语前十二段总长 60 秒，光缝转场 2.16 秒，追加四段及结束过渡合计 25 秒，结语总长 87.16 秒。「始」「终」字画面各另计 2.4 秒，说明页由玩家自行翻页，不计入上述时长。每部分包含淡入、文字停留、淡出及段间停顿，按字数分配时间；最后三段的停留仍逐步拉长。

生还正文结束后播放 `content/结语.md` 的十二段原文：沿用开场白的居中渐显渐隐，背景逐段过渡到暖白，再以中央光缝扩开的转场进入 `content/结语_尾声.md` 的四段追加文字；尾声第二段保留两行排版并放大字号。共十六段，全部结束后显示亮色「终」字画面，再自动返回主页。每次成功生还都会播放，死亡结局不播放。

正文以 `content/游戏文案_留待明日.md` 为唯一来源，分支规则依据同目录的 `制作说明与参考.md`。主角固定为维克多·弗兰克尔；对白、配角和分支包含文学改编，五条死亡路线为假设分支。

- 8 章、56 个场景，包含序章、5 条完整死亡支线及生还后的两种任务。
- 条件段落按玩家先前的选择显示；复述会使用实际选过的笑话原话。
- 旁白、环境和心理独白按段落或段落群显示；对话统一为 `人物：“台词”`，每句话单独停顿。默认由玩家手动继续。开启自动阅读后，旁白和对话会连续播放，到下一个选项时停止；快进直接补全文字并快速推进旁白、对话和场景，直到下一个选项。场景字幕在手动模式下灰显自动按钮，已开启的自动阅读可以经过字幕继续播放。
- 选项页不预选答案，空格和背景点击不能跳过选项；再次到达时标注上次选择。死亡后可回到影响本次结局的关键选择，回退后的选择状态重新计算。
- 阅读设置提供五档自动翻页速度，与逐字速度分开调节。
- 保留原有插画、美术风格、移动端布局、流程图、12 项成就、回看、阅读设置（字号、行距和速度）、3 个手动存档及逐页自动存档。

空格 / Enter 继续；Esc 暂停；1 / 2 选择；H 隐藏或恢复正文。存档、节点和成就存于当前浏览器，不能跨设备同步。清除网站数据会清除存档。

本稿使用独立的本机记录空间；进入网页后从新稿序章开始。前一个剧本的存档与阅读日志不会载入本稿。

## 编辑与检查

`js/story-data.js` 是随网页发布的编译数据；修改文案或对白标记后执行：

```sh
python3 tools/compile_story.py
node tools/verify-routes.cjs
node tools/verify-reading.cjs
node tools/verify-player.cjs
node tools/verify-timing.cjs
node tools/verify-retry.cjs
node tools/verify-introduction.cjs
node tools/verify-conclusion.cjs
node tools/verify-backgrounds.cjs
node tools/verify-motion.cjs
node tools/verify-music.cjs
```

`tools/tomorrow.py` 负责新稿编译和场景映射，`tools/speech.py` 标记实际对白的说话人并拆分句子。时间、地点显示为场景字幕；制作编号、跳转和条件说明不向玩家显示。正文中人物的叙述与动作保留，只将直接对白调整为逐句阅读格式。

`js/introduction.js` 管理开场白与生还结语的时序、配色和首次观看记录，`js/core.js` 管理条件和分页，`js/player.js` 管理阅读与存档，`js/shell.js` 管理开始界面、流程图和成就。样式位于 `styles/`，原有插画及生成说明保留在 `assets/`。

验证覆盖 413 条完整路径、全部 216 段稿件内容、条件文字、笑话原话回放、存读档、章节回跳、五条死亡线的关键选择回退、选项保护、自动播放到选项、逐句手动停顿，以及开场白的首次播放、回顾和阅读位置恢复。控制逻辑通过模拟 DOM 验证。浏览器工具访问策略阻止了本机预览，本轮未进行实际浏览器及手机布局验收。

## 字体

正文、开场白、结语及阅读回看使用本地嵌入的思源宋体 Regular 子集；「始／终」使用思源宋体 Heavy 子集及横向收窄排版，呈现类似 EVA 标题的粗明朝气质。两份衍生字库已分别更名为 Tomorrow Songti 与 Tomorrow Mincho Title，保留 Adobe 原版权及 SIL OFL 1.1 授权，可以随网页一起发布。字体、授权、来源哈希与覆盖信息见 `assets/fonts/`，不需要玩家安装字体，也不依赖字体 CDN。

当前中文字符已检查覆盖，界面回车符号「↵」允许由系统符号字体补足。字体解码与实际字形渲染检查通过；这不等于实际浏览器字体加载验收。

文案增加新字后，参考 `assets/fonts/README.md` 重新生成字库，并在有 `fonttools[woff]` 的 Python 环境运行 `python3 tools/verify_fonts.py`。

## 页面与背景过渡

主页、流程图、成就与正文之间使用短黑场过渡；正文换页、选项、操作说明和阅读面板使用轻量渐入，选项确认与弹窗关闭有渐出。读档与死亡重选在黑场中恢复状态，过渡期间阻止重复输入。原有开场白、结语和「始／终」时长不变；系统开启减少动态效果时，额外过渡会直接完成。

自动模式按页显示全文，显示倒计时并按五档速度翻页。快进每页约 0.13 秒，跨过对话与字幕；两者均在选项处停止。手动模式仍按段落或逐句点击继续。暂停、弹窗与页面切换会清理旧计时，避免迟到的翻页回调。

背景只有实际加载成功后才提交到主图层，再以旧图渐隐露出新图，并预取相邻场景的插画。晚到的旧请求不会覆盖新场景；加载失败或超时会自动重试一次，仍失败则保留当前图并提供「背景未加载，点击重试」。

## 场景配乐

根据 `assets/musics/` 文件名后的中文说明，按较长的剧情段落安排全部 56 个场景。冬季营地、病营与撤营、获释后分别持续共用一首音乐，段内选项和小场景不换曲；晚霞配乐延续到清晨，死亡支线才单独切入紧张配乐。正常生还正文换曲 4—5 次，开场白与生还结语仍使用指定曲目。连续场景的同一首配乐保持播放，不因翻页重头开始；换曲约 1.6 秒交叉淡化。

音乐在首次交互后启用，右上角可开关，「暂停 → 阅读设置」可调音量。打开阅读面板时降低音量，切到后台时暂停。网页使用 `assets/musics/web/` 中的小体积 AAC 副本，原始 FLAC 不变；完整映射、来源校验和构建方法见该目录 README。
