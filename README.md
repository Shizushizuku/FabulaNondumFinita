# 留待明日

打开 `index.html` 即可游玩，也可将本文件夹作为静态网页发布到 GitHub Pages。网页和图片均在本文件夹内，无需安装运行依赖。

开场白使用 `content/开场白.md` 中的五段原文。当前浏览器首次游玩先显示四页操作说明，由玩家手动翻页，可返回上一页。最后一页必须选择「开启音乐」或「关闭音乐」后才开始，两个选项均不预选；音乐设置会保留，之后仍可用右上角开关调整。看过旧版说明但尚未选择音乐的玩家，只补看最后一页。随后开场白全屏居中渐显渐隐，最后经过黑场与「始」字画面进入正文；后续游玩自动跳过；右上角回顾提示在最初对白开始时从右侧滑入，展示四页正文后向右滑出，点击回顾后本次游玩不再提示。回顾期间暂停正文，结束后恢复原位置。切到后台会暂停开场白计时。正常动画模式下，开场白总长 30 秒；结语前十二段总长 60 秒，骤黑、渐亮至纯白的转场 2.16 秒，追加四段及结束过渡合计 25 秒，结语正文总长 87.16 秒；存活结局到结语另有 4 秒过渡（淡出 1.5 秒、黑屏停留 2 秒、淡入 0.5 秒），与正文时长分开计算。「始」「终」字画面各另计 2.4 秒，说明页由玩家自行翻页，不计入上述时长。每部分包含淡入、文字停留、淡出及段间停顿，按字数分配时间；最后三段的停留仍逐步拉长。

生还正文结束后播放 `content/结语.md` 的十二段原文：沿用开场白的居中渐显渐隐，背景逐段过渡到暖白，随后画面骤黑 0.16 秒，用 1.8 秒逐渐亮至纯白，纯白停留 0.2 秒后再进入 `content/结语_尾声.md` 的四段追加文字。文字动画沿用原样，四段分别采用横排、双列竖排、左对齐段落和放大的居中排版。共十六段，全部结束后显示亮色「终」字画面，再自动返回主页。每次成功生还都会播放，死亡结局不播放。

正文以 `content/游戏文案_留待明日.md` 为唯一来源，分支规则依据同目录的 `制作说明与参考.md`。主角固定为维克多·弗兰克尔；对白、配角和分支包含文学改编，五条死亡路线为假设分支。

- 8 章、56 个场景，包含序章、5 条完整死亡支线及生还后的两种任务。
- 条件段落按玩家先前的选择显示；复述会使用实际选过的笑话原话。
- 旁白、环境和心理独白按段落或段落群显示；对白正文只显示 `“台词”`，人物名字单独显示在线上方，每句话单独停顿。默认由玩家手动继续。开启自动阅读后，旁白和对话会连续播放，到下一个选项时停止；快进直接补全文字并快速推进旁白、对话和场景，直到下一个选项。时间地点字幕无外框，居中渐显，停留 1.5 秒后淡出并自动进入正文（淡入 0.6 秒、淡出 0.4 秒另计）。字幕期间灰显自动按钮，原有自动模式会在字幕后继续，快进会缩短字幕展示。暂停及切到后台会保留字幕的剩余时间。
- 选项页不预选答案，空格和背景点击不能跳过选项；再次到达时标注上次选择。死亡结局页显示对应死因；死亡后可回到影响本次结局的关键选择，回退后的选择状态重新计算。
- 阅读设置提供五档自动翻页速度，与逐字速度分开调节。
- 主页「从头开始」开启新一轮游戏，「流程图」可回到已解锁节点。发现新节点后，按钮显示「流程图（解锁了新的节点！）」；查看流程图后清除提醒，刷新会保留尚未查看的状态。
- 解锁新成就后，主页按钮显示「成就（解锁了新成就！）」；进入成就页后恢复「成就」。未查看状态保存在当前浏览器，刷新后仍保留，重复获得已解锁成就不会再次提醒。
- 保留原有插画、美术风格、移动端布局、流程图、12 项成就、回看、阅读设置（字号、行距和速度）、3 个手动存档及逐页自动存档。

空格 / Enter 继续；Esc 暂停；1 / 2 选择；H 隐藏或恢复正文。存档、节点和成就存于当前浏览器，不能跨设备同步。清除网站数据会清除存档。

本稿使用独立的本机记录空间；进入网页后从新稿序章开始。前一个剧本的存档与阅读日志不会载入本稿。

本轮剧情校对、人物首次介绍和前情衔接详见 `content/剧情校对记录.md`。晚霞分支扩写为一次完整的驻足观看，先显示原图，再渐变到 `assets/sunset-open-sky.png`；留在铺上的路线不会显示晚霞图。正文修改后，旧版本存档会从当前场景开头继续，保留选择与成就、清除旧回看文本。

## 编辑与检查

`js/story-data.js` 是随网页发布的编译数据；修改文案或对白标记后执行：

```sh
python3 tools/compile_story.py
node tools/verify-routes.cjs
node tools/verify-reading.cjs
node tools/verify-narrative.cjs
node tools/verify-player.cjs
node tools/verify-achievements.cjs
node tools/verify-node-notices.cjs
node tools/verify-timing.cjs
node tools/verify-presentation.cjs
node tools/verify-retry.cjs
node tools/verify-introduction.cjs
node tools/verify-conclusion.cjs
node tools/verify-backgrounds.cjs
node tools/verify-motion.cjs
node tools/verify-music.cjs
node tools/verify-death-music.cjs
```

`tools/tomorrow.py` 负责新稿编译和场景映射，`tools/speech.py` 标记实际对白的说话人并拆分句子。时间、地点显示为场景字幕；制作编号、跳转和条件说明不向玩家显示。正文中人物的叙述与动作保留，只将直接对白调整为逐句阅读格式。名字栏仅在直接对白时显示说话人，主角统一显示「我」；旁白和心理独白不显示名字。

`js/introduction.js` 管理开场白与生还结语的时序、配色和首次观看记录，`js/core.js` 管理条件和分页，`js/player.js` 管理阅读与存档，`js/shell.js` 管理开始界面、流程图和成就。样式位于 `styles/`，其中 `game-ui.css` 集中管理游戏内的白色文字、灰色禁用按钮、黑白面板、通栏分隔线对白区（人名在淡灰横线上方，与正文首字对齐）及字幕动画，开场白和结语保留原有配色。原有插画及生成说明保留在 `assets/`。

验证覆盖 413 条完整路径、全部 227 段稿件内容、条件文字、笑话原话回放、存读档、章节回跳、五条死亡线的关键选择回退、选项保护、自动播放到选项、逐句手动停顿，以及开场白的首次播放、回顾和阅读位置恢复。控制逻辑通过模拟 DOM 验证。浏览器工具访问策略阻止了本机预览，本轮未进行实际浏览器及手机布局验收。

## 字体

正文、开场白、结语、正文回看和主页辅助文字使用本地嵌入的思源宋体 Regular 子集。主页标题、游戏内章节、操作按钮、时间地点及面板使用思源宋体 Heavy 的粗明朝字形；「始／终」和右上角标题进一步横向收窄，呈现类似 EVA 标题的气质。Heavy 字库现已覆盖全部当前用字。两份衍生字库已分别更名为 Tomorrow Songti 与 Tomorrow Mincho Title，保留 Adobe 原版权及 SIL OFL 1.1 授权，可以随网页一起发布。字体、授权、来源哈希与覆盖信息见 `assets/fonts/`，不需要玩家安装字体，也不依赖字体 CDN。

当前中文字符已检查覆盖，界面回车符号「↵」允许由系统符号字体补足。字体解码与实际字形渲染检查通过；这不等于实际浏览器字体加载验收。

文案增加新字后，参考 `assets/fonts/README.md` 重新生成字库，并在有 `fonttools[woff]` 的 Python 环境运行 `python3 tools/verify_fonts.py`。

## 页面与背景过渡

主页、流程图、成就与正文之间使用短黑场过渡；正文切换场景、段内换图或进入时间地点字幕时，也先淡出至黑屏，停留 0.12 秒后淡入新画面。正文换页、选项、操作说明和阅读面板使用轻量渐入，选项确认与弹窗关闭有渐出。读档与死亡重选在黑场中恢复状态，过渡期间阻止重复输入。原有开场白、结语和「始／终」时长不变；系统开启减少动态效果时，额外过渡会直接完成。

自动模式按页显示全文，显示倒计时并按五档速度翻页。快进每页约 0.13 秒，跨过对话与字幕；两者均在选项处停止。手动模式仍按段落或逐句点击继续。暂停、弹窗与页面切换会清理旧计时，避免迟到的翻页回调。

背景只有实际加载成功后才提交到主图层，再以旧图渐隐露出新图，并预取相邻场景的插画。晚到的旧请求不会覆盖新场景；加载失败或超时会自动重试一次，仍失败则保留当前图并提供「背景未加载，点击重试」。

## 场景配乐

根据 `assets/musics/` 文件名后的中文说明，按较长的剧情段落安排全部 56 个场景。冬季营地、病营与撤营、获释后分别持续共用一首音乐，段内选项和小场景不换曲；晚霞配乐延续到清晨。死亡支线入口沿用前一段配乐，出现身体不适、无法支撑或明确危险时才淡入紧张配乐；提示位置由正文中的隐藏配乐标记控制，读档会恢复当前页应有的配乐。正常生还正文换曲 4—5 次，开场白与生还结语仍使用指定曲目。连续场景的同一首配乐保持播放，不因翻页重头开始；换曲约 1.6 秒交叉淡化。

开始菜单、流程图和成就页保持静音，返回菜单时停止当前音乐。音乐在进入开场白或正文后按开关设置播放，首次交互解锁浏览器音频；游玩提示最后说明右上角音乐开关，并建议佩戴耳机。右上角可开关，「暂停 → 阅读设置」可调音量。打开阅读面板时降低音量，切到后台时暂停。网页使用 `assets/musics/web/` 中的小体积 AAC 副本，原始 FLAC 不变；完整映射、来源校验和构建方法见该目录 README。

死亡配乐切入点：夜班线在第四天穿错木鞋、显出疲惫失常时；监工线在右臂抬不起来时；劳役线在眼前开始发黑时；报复线在被拖回病区时；转运线在木棚上栓、闻到危险气味时。到站后的劳役营字幕处先转入平缓日常配乐，避免夜班线提前沿用到站的紧张配乐。
