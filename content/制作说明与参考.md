# 《留待明日》制作说明与参考

本文档供编剧、程序与课程展示使用，不进入人物叙述。主稿为《游戏文案_留待明日.md》，已统一采用第一人称，并补入身份、时间与地点的序章。全部分支合计约 1.2 万汉字；单次游玩只显示所经分支。

## 主角与时空

主角明确为维克多·弗兰克尔，开场时三十九岁，是来自维也纳的犹太医生，专业为神经科与精神科。妻子蒂莉原为护士，两人在医院相识。1942年9月，他与妻子、父母被押往特雷津；1944年，他与妻子被转往奥斯维辛—比克瑙，数日后又被转往巴伐利亚的考费灵，此后到图尔克海姆。身份与先后顺序依据[维克多·弗兰克尔研究所官方年表](https://www.viktorfrankl.org/biography.html)。

本稿将开场设在1944年秋的奥斯维辛，01中补写前往考费灵的转场，15前标明1945年春的图尔克海姆。它是以这些经历为原型的互动改编，配角设置、日常细节、对白和假设分支均包含创作，不将整条游戏路线视作传记的逐日重现。故事中的主角此时并不知道后来亲人的结局。

## 显示规则

- 正文与行动选项采用第一人称；人物对话中的“你”“您”等称呼按说话对象保留。叙述只写主角能够感知、回忆或从他人处得知的事。
- 所有节点编号、跳转提示、条件方括号和“记录”行都属于制作标记，玩家界面应隐藏。
- 00、01、15中加粗的时间、地点正常显示，可制作成开场或转场字幕。
- 02、08B、12B、14A、19A 为死亡结局，均有完整经过；不得在上一个选项之后直接弹出死亡提示而略去这些段落。
- 死亡支线在“我”的感知中止处停笔，不叙述自己的尸体或死后他人的行动。“结局提示”单独显示“死亡。本次故事结束。”，作为界面文字，不属于主角的自述。
- 08、12、14、20、21 的分支属于自动结算，玩家不应再次选择已经发生的事实。
- 13A 应回调玩家在 11A 或 11B 选择的笑话正文。可显示引号内的笑话，不必重复当时马丁的反应和场景。
- 条件段落只显示符合状态的一段；后续无条件段落接在它后面。
- 不设置道德分、意义分或善恶结局评级。片中人物不知道哪些行动最终会使自己生还。

## 两组复合条件

笑话追查：

| 笑话内容 | 是否复述 | 结果 |
|---|---|---|
| 改编瓦尔特情诗 | 是 | 14A：来源被追出，遭到报复。 |
| 改编瓦尔特情诗 | 否 | 14B 第一条件段：这次笑话没有从埃米尔处传出去。 |
| 手术室笑话 | 是或否 | 14B 第二条件段：内容与追查对象无关。 |

为使四种组合都成立，14 的全营查问由厨房里另一场模仿引起；只有“情诗改编＋复述传播”会留下追向主角的线索。

纸片与共同记忆：

| 纸片 | 曾否分享 | 结果 |
|---|---|---|
| 保留 | 任意 | 20A：使用原始记录。 |
| 烧毁 | 是 | 20B：共同补记，按记录内容显示对应段落；仍有缺失。 |
| 烧毁 | 否 | 20C：独自补记，保留无法确认之处。 |

看过演出影响 16 的相认方式；即使没有去听演出，主角也会在 16 第一次认识塞缪尔，因此仍可以在 16A 分享记录。歌者不能记起从未听过的内容，也不能将缺损资料完整复原。
