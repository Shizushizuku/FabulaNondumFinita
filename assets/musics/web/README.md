# 网页配乐

这些 AAC（M4A）副本由项目原有 FLAC 转换而来，原始文件保留在上一级目录。网页按需加载当前曲目，不会一次加载全部音乐。

| 文件编号 | 使用场景 |
|---|---|
| 005 | 开场白，持续至「始」过场结束 |
| 007 | 生还结语，持续至「终」过场结束 |
| 003 | 06A 晚霞，并延续到 07 清晨；未看晚霞则 07 沿用营房配乐 |
| 018 | 08—14B 冬季营地的整段经历，包括病区、演出、笑话与查问，不随小分支换曲 |
| 041 | 00—01 抵达与剥夺，以及五条死亡支线 |
| 056 | 03—06B 营房日常、奥托家事与分面包，未看晚霞时继续覆盖 07 |
| 008 | 15—19B 病营、记录、分享、引火、撤营及获释的连续段落 |
| 023 | 主页／流程图／成就，以及 20—22 获释后的连续段落 |

配乐按长剧情段落组织，生还正文仅换曲 4—5 次；各段中的选项和小场景不换曲。完整的 56 场景映射在 `js/music-data.js` 和 `manifest.json` 中。连续场景使用同一首音乐时不重播；更换曲目时约 1.6 秒交叉淡化，新曲能够播放后才淡出旧曲。

开始菜单、流程图和成就页不播放音乐，返回菜单时会停止当前播放。首次交互后解锁音频，进入开场白或正文时才按开关设置播放；浏览器若阻止播放，可点击右上角「开启音乐」。右上角可以关闭音乐，「暂停 → 阅读设置」可调整音乐音量。阅读面板打开时降低音量，切到后台时暂停，返回时恢复。

播放使用两个循环音轨。HTTP 网页使用 Web Audio GainNode 淡化，本地文件预览使用音量渐变回退。音量、音乐开关保存在当前浏览器；播放失败可通过按钮重试，不影响正文阅读。

`manifest.json` 记录原始文件、原始 SHA-256、生成文件 SHA-256 和时长。使用 macOS 自带编码器重新生成：

```sh
python3 tools/build_music.py
node tools/verify-music.cjs
```

构建时需要系统的 `/usr/bin/afconvert`、`/usr/bin/afinfo`；网页运行不需要安装编码器。
