# 网页配乐

这些 AAC（M4A）副本由项目原有 FLAC 转换而来，原始文件保留在上一级目录。网页按需加载当前曲目，不会一次加载全部音乐。

| 文件编号 | 使用场景 |
|---|---|
| 005 | 开场白，持续至「始」过场结束 |
| 007 | 生还结语，持续至「终」过场结束 |
| 003 | 06A，走到外面看晚霞 |
| 018 | 清晨出工、风雪车辙、寒冷营地与取暖 |
| 041 | 抵达与剥夺、监工威胁、笑话追查、逃亡、转运及五条死亡线 |
| 056 | 营房日常、分面包、暂时脱险 |
| 008 | 病区倾听、记下托付、分享记录、获释与补记 |
| 023 | 主页／流程图／成就、仓房演出、笑话、写作与生还后的日常 |

完整的 56 场景映射在 `js/music-data.js` 和 `manifest.json` 中。连续场景使用同一首音乐时不重播；更换曲目时约 1.6 秒交叉淡化，新曲能够播放后才淡出旧曲。

首次点击页面后启用播放；浏览器若阻止播放，可点击右上角「开启音乐」。右上角可以关闭音乐，「暂停 → 阅读设置」可调整音乐音量。阅读面板打开时降低音量，切到后台时暂停，返回时恢复。

播放使用两个循环音轨。HTTP 网页使用 Web Audio GainNode 淡化，本地文件预览使用音量渐变回退。音量、音乐开关保存在当前浏览器；播放失败可通过按钮重试，不影响正文阅读。

`manifest.json` 记录原始文件、原始 SHA-256、生成文件 SHA-256 和时长。使用 macOS 自带编码器重新生成：

```sh
python3 tools/build_music.py
node tools/verify-music.cjs
```

构建时需要系统的 `/usr/bin/afconvert`、`/usr/bin/afinfo`；网页运行不需要安装编码器。
